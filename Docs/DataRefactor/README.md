# Data Refactor & Designer Guides

Thư mục này chứa toàn bộ tài liệu hướng dẫn về cấu hình dữ liệu và các quy chuẩn authoring cho Game Designer và Developer.

## 📖 Danh Sách Tài Liệu

- **[DesignerSetup.md](DesignerSetup.md)**: Quy tắc tạo và quản lý ScriptableObject, cấp phát ID cho Base, quy trình chạy bộ kiểm tra dữ liệu `GameDataValidator`.
- **[DesignerTypeManual.md](DesignerTypeManual.md)**: Hướng dẫn tạo Asset từ các kiểu có sẵn và quy trình tạo kiểu dữ liệu mới (ví dụ: Ability Heal).
- **[EntityAuthoring.md](EntityAuthoring.md)**: Hướng dẫn gắn `UnitAuthoring` và `BuildingAuthoring` trên Prefab / Scene.
- **[BlobDefinitions.md](BlobDefinitions.md)**: Cấu trúc các struct BlobAsset (dành cho Technical Designer và Programmer).

> Để xem quy trình làm việc tổng quan, hãy mở [Trang chủ tài liệu (Docs/README.md)](../README.md).
