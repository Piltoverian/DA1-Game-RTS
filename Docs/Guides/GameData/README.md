# Hướng dẫn dữ liệu cho người thiết kế

Thư mục này chứa toàn bộ tài liệu hướng dẫn về cấu hình dữ liệu và các quy chuẩn thiết lập dữ liệu cho Game Designer và Developer.

## 📖 Danh Sách Tài Liệu

- **[RegistryPresentation.md](RegistryPresentation.md)**: Cơ chế danh mục dữ liệu hiện tại, khởi tạo duy nhất từ `Awake` và tra icon/tên/prefab trên tài nguyên.

- **[DesignerSetup.md](DesignerSetup.md)**: Quy tắc tạo và quản lý ScriptableObject, cấp phát ID cho Base, quy trình chạy bộ kiểm tra dữ liệu `GameDataValidator`.
- **[DesignerTypeManual.md](DesignerTypeManual.md)**: Hướng dẫn tạo Asset từ các kiểu có sẵn và quy trình tạo kiểu dữ liệu mới (ví dụ: khả năng Heal).
- **[EntityAuthoring.md](EntityAuthoring.md)**: Hướng dẫn gắn `UnitAuthoring` và `BuildingAuthoring` trên mẫu đối tượng / Scene.
- **[BlobDefinitions.md](BlobDefinitions.md)**: Cấu trúc các struct BlobAsset (dành cho Technical Designer và Programmer).

> Để xem quy trình làm việc tổng quan, hãy mở [Trang chủ tài liệu (Docs/README.md)](../../README.md).
