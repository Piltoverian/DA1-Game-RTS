# Asset gameplay trong Fixtures

Prefab/SO được Main và registry tham chiếu qua GUID là dữ liệu runtime. Giữ asset và `.meta`; không xóa theo tên Tests hoặc Fixtures.

Runner/fixture source kiểm chứng dùng một lần đã dọn. Kết quả còn cần cho việc sửa code nằm trong [CurrentState](../../../Docs/Maintenance/CurrentState.md); luật thông tin ở [FOW](../../../Docs/Architecture/FogOfWarRendering.md).
