# Terrain textures

Four 64x32 diamond grass frames, extracted from the local Age of Empires Rise of Rome installation during terrain research. Their Unity GUIDs are preserved from the approved terrain theme. These are existing reference assets; migration does not establish redistribution rights or replace them with original art.

Only frames 0–3 are used. Keep Read/Write enabled for runtime atlas packing, Point filtering, no mipmaps and NPOT scaling disabled. Ramp color uses texture luminance; cliff walls are procedural. Ground vertices sample the diamond through fixed UVs, never adjust gameplay grid anchors.
