# UI RTS tu tiên — concept v1

Created with the built-in image_gen tool using the imagegen skill.
These are visual concept sheets, not sliced sprites or a working Unity UI.

## Art direction

- Classic RTS layout: resource strip at top, minimap bottom left, selection bottom center, command grid bottom right.
- Dark jade, charcoal wood, aged brass, parchment text; restrained cloud ornaments.
- Resources: Linh mộc, Linh thạch, Đan dược, Linh khí, Môn đồ.
- Selection: Kiếm tu / Trúc Cơ, health and energy, stats, group portraits.
- Commands: movement, attack, guard, stop, flying sword, sword formation, meditation, healing, sect hall, spirit mine, alchemy, research.
- Kit: button states, tooltip, training queue, building info, cultivation research, menu.
