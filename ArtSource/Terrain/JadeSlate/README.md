# Jade Slate — current generated material library

`materials.png` is original artwork generated with the built-in ImageGen tool on 2026-10-10. Four equal quadrants: lush meadow, planar mountain slate, sparse meadow, cliff slate. Exact prompt is in `prompt.md`. `build.json` records source hash, output count and rasterization method.

The 78 canonical textures are already checked in. The offline Python generator was removed on 2026-10-10. Refresh Unity, then use `RTS/Terrain/Import Jade Slate Material Library` to import existing textures; four small decorations retain the user's cleaned Photoroom artwork, preserved under `Decorations/`. The generated sheet is a material source, not a sprite atlas. No game screenshot or third-party game asset is bundled.
